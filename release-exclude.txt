# Paths that must not be included in a Qronos release build.

# One path per line, relative to the repository root. A trailing slash means a
# directory and everything under it. Blank lines and lines starting with # are
# ignored. Any packaging step can read this file, whatever it is written in.
#
# tests/test_release_hygiene.py checks this file against the repository on every
# test run: it fails if an entry no longer exists, if a file marked as a debug
# tool is not covered here, or if product code imports from tools. So this list
# cannot quietly fall out of step with the code.

# fine in software a user installs. It also refuses to run if it detects a
# release build, so a mistake here is inert rather than exploitable.
